## 0.1.0

* Converted from a native plugin to a **pure Flutter package** (Android, iOS, Web, Windows, macOS, Linux).
* Added **live search** filtering by value, code, or key (`enableSearch`).
* Added **clear button** and `onCleared` callback (`showClearButton`).
* Added optional **icons** on `SelectOptions` and selected-item checkmark in the menu.
* Added `enabled`, `accentColor`, `maxMenuHeight`, `emptyStateText`, `itemBuilder`, and `addLabelBuilder`.
* Improved `SelectOptions` with equality, `copyWith`, `toMap` / `fromMap`, and `generateCode`.
* Widened SDK constraint for broader compatibility.
* Updated README and example app around the **creatable + searchable** flow.

## 0.0.2

* Added BSD 3-Clause license.
* Added package README with usage example and API overview.
* Prepared package metadata for pub.dev publication.

## 0.0.1

* Initial release of `UnifiedDropdown`.
* Supports selecting from a list or typing a new value with automatic code generation.
